## Лабораторна робота № 6: Основи JavaScript (Конвертер і Каталог)
- **Тема проєкту:** Портфоліо фотографа, варіант 2
- **Конвертер величин:** Реалізовано конвертер обсягу даних (базова одиниця — байт `Б`, підтримуються одиниці: `Б`, `КБ`, `МБ`, `ГБ`, `ТБ`)[cite: 58, 60]. Перевірено роботу функції валідації `parseValue` для коректних і некоректних даних (порожні рядки, літери `abc`, від'ємні числа).
- **Каталог товарів:** Створено масив із 10 товарів за тематикою «Фототехніка, об'єктиви та фони»[cite: 58]. 
- **Використані методи:** 
  - Застосовано функціональні методи масивів вищого порядку: `.map()` для додавання ціни зі знижкою (`DISCOUNT = 10%`), `.filter()` для фільтрації («Дорожчі за поріг 400 грн», «Лише в наявності»), `.reduce()` для підрахунку підсумків і категорій, а також `.slice().sort()` для безпечного сортування за ціною без мутації вихідного масиву[cite: 37, 46, 47, 48, 49, 58].
  - Реалізовано делегування подій через спільний слухач на панелі `.toolbar`[cite: 37, 38, 49].
