# Лабораторна робота № 9. Компонентний підхід у React

## Опис проєкту
Цей застосунок є міграцією раніш створеного списку завдань (Todo) на компонентну архітектуру **React** з використанням інструмента збірки **Vite**.

### Основні компоненти:
- `Header` — шапка застосунку із заначенням теми та варіанта.
- `TodoForm` — форма додавання нового завдання із зазначенням терміну.
- `Filters` — перемикачі фільтрів (Усі, Активні, Виконані).
- `TodoList` / `TodoItem` — список завдань та окремі елементи з можливістю відмітки виконання та видалення.
- `Counter` — лічильник виконаних та загальних завдань.
- `ProgressBar` графічні шкали прогресу виконання загальних та актуальних завдань.

## Лабораторна робота № 13: Розробка REST API з CRUD-операціями

Базова адреса: `/api/photoshoots`

| Метод | Адреса | Дія | Успіх | Помилки |
| :--- | :--- | :--- | :--- | :--- |
| `GET` | `/api/photoshoots` | Список фотосесій (пошук, фільтр, сортування, пагінація) | `200` | `400` |
| `GET` | `/api/photoshoots/:id` | Отримання однієї фотосесії за `id` | `200` | `400, 404` |
| `POST` | `/api/photoshoots` | Створення нової фотосесії (`Location` у заголовку) | `201` | `400, 409, 413` |
| `PUT` | `/api/photoshoots/:id` | Повна заміна запису за `id` | `200` | `400, 404, 409, 413` |
| `PATCH` | `/api/photoshoots/:id` | Часткова зміна переданих полів | `200` | `400, 404, 409, 413` |
| `DELETE` | `/api/photoshoots/:id` | Видалення запису за `id` | `204` | `400, 404` |

**Параметри списку (`GET /api/photoshoots`):**
* `q` — пошук за підрядком у полі `title` без урахування регістру;
* `category` — точний фільтр за категорією (`portrait`, `wedding`, `studio`, `reportage`);
* `sort` — сортування за дозволеними полями (`title`, `price`, `createdAt`; префікс `-` означає сортування за спаданням, наприклад `?sort=-price`);
* `page` — номер сторінки (від `1`), `limit` — кількість записів на сторінці (`1–100`).

**Загальна кількість записів за фільтром:** передається у HTTP-заголовку відповіді `X-Total-Count`.  
**Формат помилок:** `{ "error": "Повідомлення", "details": ["..."] }`.  
**Команди:** `npm install`, `npm run seed`, `npm run dev`, автоматична перевірка: `npm run check`.

Базова адреса колекції: `/api/photoshoots` | Правило доступу: **Тип 2** (видалення `DELETE /:id` дозволено лише адміністратору).

| Метод | Адреса | Опис дії | Рівень доступу | Успіх | Помилки |
| :--- | :--- | :--- | :--- | :--- | :--- |

| `GET` | `/api/photoshoots` | Список усіх фотосесій (`?q`, `?category`, `?sort`, `?page`, `?limit`) | Публічний | `200` | `400` |
| `GET` | `/api/photoshoots/mine` | Список фотосесій поточного користувача | Потрібен токен | `200` | `401` |

| `POST` | `/api/photoshoots` | Створення нової фотосесії (`owner` береться з токена) | Потрібен токен | `201` | `400, 401, 409` |
| `PUT` | `/api/photoshoots/:id` | Повна заміна запису | Власник або `admin` | `200` | `400, 401, 403, 404, 409` |
| `PATCH` | `/api/photoshoots/:id` | Часткове оновлення запису | Власник або `admin` | `200` | `400, 401, 403, 404, 409` |
| `DELETE` | `/api/photoshoots/:id` | Видалення запису (**Правило Типу 2**) | Лише `admin` | `204` | `400, 401, 403, 404` |
